# بورتفوليو عبدالله عماد

موقع شخصي عربي لمطور واجهات أمامية في بداية رحلته، مبني باستخدام HTML وCSS وJavaScript فقط.

## تشغيل الموقع في Visual Studio Code

1. فك ضغط ملف `abdullah_emad_portfolio.zip`.
2. افتح Visual Studio Code.
3. اختر **File → Open Folder** ثم افتح مجلد `abdullah_emad_portfolio`.
4. افتح `index.html`.
5. أسهل طريقة للمعاينة هي تثبيت إضافة **Live Server** من قسم Extensions.
6. بعد تثبيتها، اضغط بزر الفأرة الأيمن على `index.html` واختر **Open with Live Server**.

يمكنك أيضًا فتح `index.html` مباشرة في المتصفح، لكن Live Server أفضل أثناء تعديل الملفات.

## هيكل الملفات

- `index.html` — محتوى الموقع وأقسامه.
- `css/style.css` — الألوان والتصميم والتجاوب مع الشاشات.
- `js/script.js` — زر الوضع الداكن/الفاتح، القائمة، وحركات الظهور.

## تخصيص الموقع

- غيّر النصوص داخل `index.html`.
- غيّر الألوان من المتغيرات الموجودة في بداية `css/style.css`.
- حدّث بطاقات المشاريع في قسم `projects`. البطاقات الحالية موضّحة بصفتها **أفكار مشاريع تدريبية** وليست أعمالًا مكتملة.
- البريد الإلكتروني ورابط واتساب موجودان في قسم التواصل.
- زر تبديل الوضع يحفظ اختيارك في المتصفح باستخدام `localStorage`.

## ملاحظات
